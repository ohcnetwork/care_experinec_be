# Installation

## Stable release

To install Care Experience Sandbox, run this command in your terminal:

```sh
pip install Care Experience Sandbox
```

## From source

The source files for Care Experience Sandbox can be downloaded from the [Github repo](https://github.com/ohcnetwork/care_experience_sandbox_be).

You can either clone the public repository:

```sh
git clone git://github.com/ohcnetwork/care_experience_sandbox_be
```

Or download the [tarball](https://github.com/ohcnetwork/care_experience_sandbox_be/tarball/master):

```sh
curl -OJL https://github.com/ohcnetwork/care_experience_sandbox_be/tarball/master
```

Once you have a copy of the source, you can install it with:

```sh
cd care_experience_sandbox_be
pip install .
```
